# Internationalization architecture

Rivo ships `en-US` and `zh-CN` Fluent catalogs. UI text is localized; machine protocol fields, IDs, error codes and configuration keys remain stable.

## Catalog files

A user catalog contains canonical locale metadata, revision, minimum Rivo version and Fluent messages. Validation checks UTF-8, canonical filename, size limit, metadata, syntax, control characters and the required variable schema.

## Discovery and fallback

`RIVO_LANGUAGE_DIR` selects the user catalog directory; otherwise the data directory is used. Bundled catalogs are fallback resources. A missing or invalid selected catalog falls back to embedded English and reports a local repair action. Registry access occurs only for explicit `remote-list`, `download` or `update` commands.

## Local management

`rivo language path|list|show|validate|install|remove` manages local files. Install is atomic; replacing an existing catalog requires `--yes` and preserves a `.bak`. Remove requires `--yes` and never deletes bundled fallback. TUI reload uses `/language reload`; switching uses `/language <locale>`.

## Prompt and protocol

`rivo run --language <BCP47>` selects UI and default response language for one run. `config set locale <BCP47>` persists the default. App-server `runtime_settings.response_language` controls response language without changing wire fields.
